# 3.5.0 — git add, commit and push ask instead of being denied

## Applies if
`.claude/settings.json` has `Bash(git commit *)`, `Bash(git push *)` or
`Bash(git add *)` under `permissions.deny`.

## Changes
1. `.claude/settings.json`: move `Bash(git commit *)`, `Bash(git commit)`,
   `Bash(git push *)`, `Bash(git push)`, `Bash(git add *)` and
   `Bash(git add)` from `permissions.deny` to `permissions.ask`. A deny in
   the project overrides any confirmation, so Orchestrate mode could never
   close a delivery. Every other deny stays. **Merge, do not replace.**

## Check
`jq -e '.permissions.ask | index("Bash(git commit *)")' .claude/settings.json`
succeeds and the same query on `.permissions.deny` prints `null`.
